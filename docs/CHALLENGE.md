# Challenge Técnico

El objetivo de este challenge es conocer cómo pensás, cómo encarás un problema real y cómo trabajás con herramientas que usamos en el día a día. No buscamos una solución perfecta, sino una implementación clara, prolija y funcional.

El tiempo estimado para resolverlo es de 5 a 10 horas, dependiendo del nivel de detalle y mejoras que quieras agregar.

## Consigna

Desarrollar una web app sencilla que consuma y muestre información, siguiendo un diseño provisto en Figma.

El challenge simula un caso real de trabajo dentro del club.

## Diseño

El diseño de la aplicación estará disponible en Figma.

## Requerimientos funcionales

- Mostrar una lista de elementos (ejemplo: artículos, eventos, socios, noticias, etc.).
- Permitir ver el detalle de un elemento.
- Manejo básico de estados: loading, error y estado vacío.
- La aplicación debe ser funcional y navegable.

## Requerimientos técnicos

- Frontend con Next.js y TypeScript.
- Backend simple con Node.js y TypeScript (o puede ser API routes de Next.js).
- Base de datos relacional (PostgreSQL preferentemente).
- Uso de algún ORM (en el caso de hacer un back-end).
